# MagMax Remix

A remake of the classic 1985 Nichibutsu arcade game "MagMax" (組合金剛).

## Requirements

- Python 3.10+
- pygame-ce

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pygame-ce
```

## Run

```bash
source .venv/bin/activate
python main.py
```

## Controls

- Arrow Keys: Move
- Space / Z: Shoot
- Enter: Start game / Pause

## Gameplay

- Collect robot parts (Head, Legs, Wave Beam Gun) to power up
- Enter dark craters to go underground
- Survive 4 stages: Forest, Desert, Sea, Automated City
- Defeat the final boss: Babylon
